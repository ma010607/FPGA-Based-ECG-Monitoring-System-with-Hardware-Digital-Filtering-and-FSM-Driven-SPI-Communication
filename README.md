# FPGA-Based-ECG-Monitoring-System-with-Hardware-Digital-Filtering-and-FSM-Driven-SPI-Communication
A fully hardware-accelerated real-time ECG monitoring system on FPGA, featuring digital filtering, Pan-Tompkins R-peak detection, and FSM-driven SPI display without an external MCU.
# we used zybo-z7 FPGA board, adc is MCP3208, and DISPLAY is ST7735S
